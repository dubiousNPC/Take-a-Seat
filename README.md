# Take a Seat

Sit on furniture in OpenMW. Look at a seat and press Activate to sit; press Activate again to stand.

## Requirements
OpenMW 0.49+. `scripts/SharedRay/SharedRay_v2.lua` and `scripts/AnimRefresh/AnimRefresh_v5.lua` are bundled shared services and version-guard themselves.

## Settings
Camera offset while seated, separately for first and third person. Uses the SuperSlider renderer (v6+) when installed, plain number fields otherwise.

## For other mods
`scripts/take_a_seat/sitAnim_shared.lua` is data only and safe to require and hold:

```lua
local seats = require('scripts.take_a_seat.sitAnim_shared')
local kind  = seats.getSeatType(obj.recordId)   -- "bench" | nil
local group = kind and seats.SEAT_ANIM[kind]
```

Public events sent to the player: `TakeASeat_Seated { furniture, seatType, animGroup }` and `TakeASeat_Stood {}`.

## Adding seats
- A record from a plugin that may not be installed goes in `MOD_SEAT_DATABASE` under that plugin's filename. It is merged only when the plugin is loaded.
- A vanilla record goes in `BASE_SEATS`.
- Anything unlisted falls back to `SEAT_TYPE_PATTERNS`.
- Exact record IDs beat patterns. Record names lie: three vanilla records pose as a different type than their names suggest.
- `furniture_profiles.lua` is generated by `tools/gen_furniture_profiles.py`; don't edit it by hand. Hand-listed records win over generated ones.

## Design notes
- **Resolve is fully async.** Every probe is an async rendering ray, so a sit is a chain of round-trips: push the chair clear of walls, find the seat plane, nudge the player clear. A token invalidates any chain overtaken by a new Activate, and a 3s timeout aborts one that never finishes.
- **Seat height.** Calibrated records (`SIT_PIVOT_OFFSET`) skip the rays entirely. Otherwise nine downward columns are clustered and the most-hit plane wins, with a fallback offset when nothing is found.
- **The chair is moved while seated and restored on stand.** A save made while seated stores the original placement, and loading restores it, so a chair can't drift between saves.
- **One priority profile per target kind** (`buildAnimProfiles`): idle, enter and exit. Every play and replay of the seated pose uses the idle profile.
- **The pose is re-issued only when lost.** The AnimRefresh subscription passes no `verify`, and the refresh checks `animation.isPlaying` first: replaying a looping pose restarts it from frame 0.
- **Enter and exit one-shots** have a 1s backstop timer, because a missing clip never sends its ended event.
- **Beds are off** (`BEDS_ENABLED = false`) until the sleeping clips are confirmed in every skeleton set.
- Sitting restores fatigue up to its fortified maximum and never lowers it.
